# 06 - cube 前端设计（Next.js）

> 目录：`cube/apps/web`（Next.js App Router + TailwindCSS + SSE）。页面状态全部来自服务器（后端为唯一事实源），刷新/断线自动恢复。

## 1. 页面路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 首页 | 入口页（创建比赛入口 → `/create-tournament`，需 create token；**卡池为下拉选择**，来自公开 `GET /pools`，只含名称+数量） |
| `/t/:tid` | 报名页 | 填写 player id + 展示 token；加入后跳转 `/t/:tid/draft/:pid` |
| `/t/:tid/draft/:pid` | 选牌页 | **每玩家独立 URL**（同机多用户测试）；含已选卡搜索过滤 |
| `/t/:tid/deck/:pid` | 构筑页 | 独立 URL；卡牌搜索面板（一键加副卡组） |
| `/t/:tid/matches/:pid` | 对局页 | 独立 URL；对阵/房间信息 |
| `/admin` | 管理页 | 阶段控制、暂停、security 开关、卡池维护、回溯 |

**每玩家身份解析**（dev_docs/07 §2.1）：`pid` 取自 URL；token 从 localStorage（`yc_token_<tid>_<pid>`，同机多用户互不干扰）或 cookie 读取；缺失时页面弹出 **token 输入框**（super admin token 可作为万能 token 进入任意玩家页面）；若该 tournament 已关闭 token 鉴权（`authRequired=false`，公开信息接口下发），则不弹输入框，仅凭 pid 进入。

## 2. 选牌页布局（对应 original_guide.md 的 UI 要求）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：player id | token(默认隐藏,可切换) | 比赛信息(hover 详情)   │
│       当前牌堆 #k / 剩余牌堆数 | 当前牌堆剩余牌数 |              │
│       正在选牌的 player | 剩余时间(当前轮) | 搜索栏               │
├──────────────────────────────────────────┬─────────────────────┤
│ 左侧：已选卡牌                             │ 右侧：待选牌堆        │
│  ┌─ 主卡组 (n/40~60) ─┐                   │  当前轮次其他人：     │
│  │ 每行10张 小卡图     │                   │  只显示背面图案 + 数量 │
│  ├─ 额外卡组 (n/15) ──┤                   │  当前轮次自己：       │
│  │ 每行10张 小卡图     │                   │  每行5张 正面卡牌      │
│  ├─ 副卡组 (n/15) ────┤                   │  背景 = 剩余秒数倒计时 │
│  │ 每行10张 小卡图     │                   │  (动态光效/进度条)     │
│  └─────────────────────┘                  │                     │
│  hover 卡牌 → 放大卡图 + 完整效果文本       │  点击/拖拽 → 确认弹窗  │
└──────────────────────────────────────────────────────────────┘
```

- **顶部信息栏**（固定）：player id、token（默认隐藏，点击眼睛切换）、比赛基本信息（hover 显示详情：人数/卡池/模式/当前阶段）、当前牌堆编号、当前牌堆剩余牌数、剩余牌堆数、正在选牌的 player id、当前选牌剩余秒数。
- **搜索栏**：可以搜索任意卡名/code，显示卡图、文本、该卡牌的当前比赛状态（初始大卡池未包含/已被当前用户选走/当前用户在之前卡堆见过但未选择/未知（尚未出现、或者在当前用户选牌前就在之前卡堆被选走））
- **左侧区域**：主/额/副三区，每行 10 张小卡图，超出行数 scroll 扩展；hover 显示放大卡图+效果文本；每区头部显示 `当前/上限`；支持拖拽：区域内换序、主/额/副之间移动（**类型不符的目标区拒绝**——主卡组不能放额外卡、额外区不能放主卡，副卡组两者皆可）；拖拽+点击操作均弹确认。
- **右侧区域**：
  - 非自己轮次：只显示牌堆剩余数量（卡背图案），不泄露卡牌内容；
  - 自己轮次：与左侧一致的正卡图展示（每行 5 张）；
  - 区域背景动态显示剩余秒数倒计时（数字 + 渐隐/进度光效）。
- **交互**：点击卡牌 = 加入主卡组（弹确认）；拖拽到目标区 = 加入目标区（类型正确才有效，弹确认）。

## 3. 构筑页布局

- 左侧三区与选牌页一致（此时仍然可自由拖动整理）。
- 右侧变为**放弃区**：显示当前牌堆剩余未选卡（全部正面），可拖动回选（在限制内）或丢弃；仍显示构筑阶段倒计时背景。
- 操作：`下载 ydk`（当前左侧选区导出，任意时刻可用）、`锁定卡组`（服务器校验，不合格提示具体错误；锁定后可解锁直到时限）；阶段结束逻辑见 05-4。

## 4. 对局页布局

- 当前轮次对阵表（桌号 / A vs B / 状态 / 比分）。
- 轮到自己对局时：显示 srvpro 服务器地址+端口+房间密码（醒目复制按钮）与"请使用 ygopro 客户端加入"引导；状态轮询（对局中 → 已结束 + 比分）。
- 断线/刷新后自动恢复该轮信息（服务器为事实源）。

## 5. 卡图加载

- 后端**不存储/传输原始 pics**；只下发 card code + 文本数据。例外：服务器保存低清 avif 缩略图（`pics.avif_dir`，见 05 §9.7）。
- 前端实现 `CardImage` 组件，候选顺序：① 玩家本地授权的 **ygopro 根目录**目录句柄（`<root>/pics/` 与 `<root>/expansions/*/pics/`）→ ② 手动配置的本地路径（`pics/` 与 `expansions/pics/`，HTTP 无法列目录故不含 per-pack 子目录）→ ③ 服务端低清 `GET /api/pics/:code.avif` → ④ 服务端原图代理 `GET /api/pics/:code`（config.yaml `pics.ygopro_root`，见 05 §9.7）→ ⑤ 空白卡占位（卡名）。
- 本地路径：设置页配置一次（localStorage `yc_local_pics`），格式为 `<ygopro_root>`。

## 5.1 卡牌 hover 详情

- 所有卡牌（左侧区域/右侧牌堆/搜索列表）hover 显示：**放大卡图 + 卡名 + 效果文本**（`CardWithTooltip`，数据来自 `/t/:tid/cards` 的 `desc` 字段）。

## 5.2 退出登录

- 构筑页提供 `CardSearch` 面板：按名称/代码查询 `GET /t/:tid/cards?q=`，结果列表显示卡图+名称+code，命中玩家选牌池的卡片可一键加入副卡组；构筑阶段拖拽/搜索双通道。

## 5.2 退出登录

- 顶栏身份组件提供 logout 按钮：清除 `yc_tid/yc_pid/yc_token` cookie（服务端无状态）与当前 player 的 localStorage token，随后提示重新输入 token 或重新报名。

## 5.2 卡牌搜索

- 构筑页提供 `CardSearch` 面板：按名称/代码查询 `GET /t/:tid/cards?q=`，结果列表显示卡图+名称+编号+效果文本（hover），命中未使用选牌池的卡可一键加入副卡组；选牌页左侧三区顶部提供**搜索过滤框**（实时过滤主/额/副三区）。

## 5.3 信息脱敏（非管理页面）

- **SSE 事件不携带卡牌/卡组内容**：`pick` 事件只有 `{playerId, auto}`（不含卡 code）；`deck` 事件只有 `{playerId}`；`match` 事件不含 roomName（客户端各自通过 `/t/:tid/matches` 取自己的房间信息）。客户端收到事件后自行 refetch 全量状态（服务器只返回本人数据）。
- 公开 `GET /pools` 只返回卡池名称与数量，不含卡 code。
- 管理页（/admin）以外不展示 admin token、srvpro 地址、他人卡组/选牌内容。

## 5.5 界面语言与排版

- 全部 UI 文案使用**中文**（按钮、状态、提示、错误信息等），技术术语（ydk、token、card code）保留原文。
- 排版规范：暗色桌布主题（felt 深绿 + gold 强调）；信息层级 = 顶栏（比赛/牌堆/倒计时）→ 主区（三区卡组 + 右侧牌堆）→ 底部操作条；卡片 10/行（左）与 5/行（右）；hover 详情、确认弹窗、倒计时呼吸光效。

## 6. 实时性（SSE）

- 后端 `realtime/` 按 tournament 广播事件：`phase-changed`、`pack-state`（轮次/剩余数/当前选牌者）、`timer-tick`（秒级，仅对当前选牌者精确）、`pause-state`、`deck-state`、`match-state`、`system-notice`。
- 前端 `useTournamentStream(tid)` hook 统一消费；断线自动重连 + 重连后全量拉取状态（`GET /t/:id/state`）。
- 计时器显示以前端 tick + 服务器绝对截止时间（`deadline_at`）计算，避免 SSE 抖动。

## 7. 组件拆分（apps/web/components）

```
TopBar (身份/比赛信息/阶段)
DeckZone (主/额/副三区, 每行10, 计数, 拖拽)
PackZone (右侧待选/放弃区, 每行5, 倒计时背景)
CardImage (本地卡图 + fallback)
CardHoverCard (放大卡图 + 效果文本 tooltip)
CountdownBackground (倒计时光效背景)
ConfirmModal (选牌/移动确认)
PauseControl (发起暂停/投票/状态)
LockBar (构筑阶段锁定/解锁/下载 ydk)
MatchTable (对阵表 + 房间信息)
```

样式基调：卡牌桌游暗色主题（深绿/深蓝绒面质感），动画克制但有反馈（选牌飞入、倒计时呼吸光、锁定成功闪光）。

## 8. 验收标准

1. 选牌页在"他人轮次"不泄露任何卡牌信息（网络请求也不含牌堆内容，仅数量）。
2. 点击/拖拽选牌均有确认；拖入类型不符区域被拒绝并提示；主→副、副→主、区内部移动均正常。
3. 倒计时背景随剩余秒数动态变化；超时后端自动选牌后 UI 秒级同步。
4. 断线重连（刷新页面）后恢复到当前精确状态（含进行中的计时截止时间）。
5. 卡图：本地路径可读时显示卡图；未配置/缺失时显示空白占位卡（不报错、不阻塞）。
6. 构筑页锁定后服务器校验错误能逐条展示；ydk 文件格式可被 ygopro 客户端直接导入。
