# YGOPro 对战交互与视觉复刻审查（2026-09-20）

## 范围与依据

本轮从本地 `ygopro` 的 `cube-server` 提交 `b56f0d6a9e9751895228e1c3ad902d3818f15464` 阅读原生实现，再对照网页实际渲染和真实 srvpro 对战。不是根据客户端截图推断协议，也没有移植原生贴图或另建客户端资源副本。已有本地卡图、低清 AVIF、公开信息权限继续复用。

主要依据：

| 原生文件 / 函数 | 职责 | 网页对应实现 |
| --- | --- | --- |
| `gframe/game.cpp` GUI 初始化 | 卡片详情、按钮、选择窗口、阶段切换控件 | `DuelClient.tsx`、`duel.css` |
| `gframe/drawing.cpp` `DrawCard`、`DrawMisc`、`DrawStatus`、`DrawSpec` | 卡片方向、选择轮廓、旋涡、连锁、攻击箭头、攻守颜色、召唤/阶段提示 | `DuelClient.tsx`、`BattleFeedback.tsx`、`battle-feedback.css` |
| `gframe/client_field.cpp` `MoveCard`、`GetCardLocation`、选择合计检查 | 手牌/场地区域布局、移动插值、合法选择 | `native-visuals.ts`、`interaction.ts`、协议 `selectionValid` |
| `gframe/event_handler.cpp` 场地点击、`CancelOrFinish` | 单卡动作菜单、区域浏览、右键完成/取消、装备注视与对象标识 | `DuelClient.tsx`、`interaction.ts` |

## 审查结果与本轮修改

### 操作与信息

1. 原生选中单卡或达到可确认的选择上限时直接提交。网页之前所有选择都要求再按确认，且可以超过上限。本轮对卡片、祭品、合计、排序等限制选择数，合法且达到上限才自动确认，仍能在未完成时取消已选卡；可提前完成的选择保留确认。
2. 原生右键区分关闭浏览窗口、取消、完成。网页现在不会通过右键取消已经部分完成的卡片/祭品选择，也不会穿过对局记录、展示窗口或详情去响应底层提示。可以取消的区域选择发送区域专用编码，必须选择的表示形式不能跳过。
3. 新增提示对象与 revision 的提交门控。快速双击、JSON 提示先于二进制提示到达、旧窗口事件、已提交后服务器尚未回复，都不能复用同一次响应。明确的拒绝或新的重试提示允许再次操作。
4. 默认保留“有可用效果时响应”的中央两步确认；原生忽略连锁模式遇到 `spe_count=0x7f` 的诱发选择不能跳过。是否连锁的窗口继续允许查看场面。
5. 单张场上/手牌的动作放在附近的紧凑菜单中，避免每个动作重复一张同样的大卡图。区域操作继续显示候选卡及“查看全部”，手机上菜单限制在视口内。
6. 怪兽显示实时攻击/守备，增加与降低使用不同颜色；超量显示阶级，连接怪兽显示连接值。详情可显示正在查看的场上实体的实时数值。比较使用服务器基础值，缺失时才回退元数据。
7. 增加可攻击箭头、表侧无效/禁止标记、实时灵摆刻度；悬停或键盘聚焦卡片时标记相互装备/对象关系。装饰层不接收点击，防止悬停时标记消失造成丢失点击。
8. 多个连锁标记错开显示；新卡占据旧效果来源的位置时，不再仅凭位置附加旧标记。连锁结束后不继续用动画历史给场上卡片贴标。
9. 旧大师规则不显示额外怪兽区；共享额外区同时检查双方对应位的禁用标志。保留双方场地中心对称和不同表示形式的统一卡片尺寸。
10. `MSG_BATTLE` 原先只保留原始日志，现在更新实际存在的攻守实体，不创建未知卡、不改变位置或泄露身份。攻击记录追加是否直接攻击，里侧目标与直接攻击不再混为一谈。
11. 原生 `CARD_QUESTION` 限制查看墓地通过 `MSG_PLAYER_HINT` 实现；网页此前忽略。本轮按实际查看者锁定双方墓地，收到解除提示后恢复，重置/重连快照兼容旧数据。
12. 独立 `/duel/play` 的规则摘要缩短为中文，详细卡组限制折叠显示，减少竖屏顶部占用。

### 动画

- `MSG_MOVE`、`MSG_DRAW`：从实际场上位置向目的区域移动卡图/卡背；对方抽卡和非公开目的区域不使用推断出来的卡号。
- 通常/特殊/反转召唤：目的区域光圈与文字标记。
- `MSG_BECOME_TARGET`：直接标记被选择的场上/区域对象。
- `MSG_ATTACK`：连接实际攻击者和被攻击卡的动态箭头；直接攻击指向另一方区域，不需要对方里侧卡片的卡号。
- 伤害、回复、支付、生命值调整：带意义的增减数字和生命值滚动。
- 回合/阶段：短时提示条，保留顶部的可点击阶段控件。
- 表示形式转换：独立的旋转/透明度过渡，避免破坏对方场地的父级旋转。

动画层不接收指针事件。快照、重连和录像跳转清理过期反馈；高速录像跳过长动画；系统减少动态效果时保留静态意义提示并关闭移动/旋转动画。新层使用 CSS/SVG 和现有 CardImage，不新增大体积美术依赖。

## 后续复刻边界

这轮不是原生客户端的逐帧复制：网页采用适合竖屏的平面场地，未移植原生 3D 透视、音效和全部特殊卡片动画。连接怪兽的连接区域/互相连接区域的空间高亮，以及合计选择时提前过滤不能完成的候选，仍可继续完善；现有确认始终受合法性校验约束。展示消息仍以可回看的公开卡片窗口为主，尚未完整区分所有 `skip_panel` 的原生翻面呈现。上述内容不应在发布说明中描述为已经完全复刻。
