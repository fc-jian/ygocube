## 任务描述

本项目的目的是基于开源 `ygopro` 游戏引擎及服务端 `srvpro` 改写一个全流程 “轮抽模式” YGO 游戏系统。

轮抽模式（Cube）指的是一种分为 选牌、构筑、对战比赛 三个阶段的特殊 TCG 游戏模式。

一次完整的 Cube Tournament 流程如下：
1. 确定参与人数、卡池、比赛模式（默认根据玩家数目决定）、对战模式（Single game 或包含更换Side deck 的 Match）等基础信息和下面涉及的各项参数。生成对应的URL链接。
2. 玩家通过链接打开网页UI，报名参加。
3. 所有玩家报名后启动游戏，开启选牌构筑阶段
- 对全卡池按照一定策略随机打乱，组成若干牌堆。每个牌堆的卡牌数目以及牌堆的数目一定都是玩家总数的整数倍（默认：完全随机打乱、每个牌堆size是玩家数目的3倍、drop last 且预先公开被 drop 的 card list）。
- 所有玩家确定圆桌顺序，每个牌堆，所有玩家顺时针轮流选牌，上一牌堆最后一个选牌的人下一牌堆则是第一个选（即最后一个选牌的人会连续选择两张牌）。因为牌堆的数目要求是玩家数目的整数倍，每个玩家都以相同次数参与每个选牌位置。
- 玩家并不知道其他玩家的选择，也不知道当前牌堆轮到自己前已被选走的卡牌。
- 每轮玩家的选择时间有限制（默认30s），超过则系统随机选牌。
4. 选完所有牌堆后，玩家从自己选择的卡牌自行构筑卡组。
- 对于单局模式，玩家需要确定主卡组（默认限制40~60张范围）、额外卡组（默认限制15张）
- 对于match模式，还需要确定备换的副卡组（默认限制15张）
5. 所有玩家确定卡组后，开启对战比赛阶段
- 按照预先设置的比赛规则排出对战表，每一轮通知每位玩家当前对手并建立游戏房间。对战结束后根据玩家上报的赛果进行下一轮排表。
- 默认：3~5名玩家，进行单循环；6~8名玩家，进行4轮瑞士轮直接决出名次。9~16名玩家，进行4轮瑞士轮决出4强选手进行半决赛、决赛。17名玩家以上也根据标准的瑞士轮+淘汰赛赛制进行。

## 目录说明

- `ygopro/` 官方 ygopro repo，如果需要修改，要求建立新的分支进行修改开发适配
- `assets/` 供 ygopro 程序调用，游戏必须的外部资源，包括卡牌数据库 `cards.cdb`、卡图文件 `pics/`、卡牌效果Lua脚本 `script/`。`expansions/` 是独立于主数据库的扩展包，格式一致。
- `srvpro/` MyCard 平台使用的 ygopro 服务器端工具包，如果需要修改，要求建立新的分支进行修改开发适配
- `cube/` 目前为空，要求在这里开发一个前面提到的web控制端，实现选牌、构筑、排表等功能，并与 ygopro/srvpro 进行交互（设置参数、建立房间、获取结果等）

## 功能要求

### ygopro/srvpro 的改动

- 对deck size（main、extra、side）提供动态可配置支持，作为建立游戏房间时的指定参数
- 对战阶段开始前记录所有玩家的固定卡组，比赛时自动加载、自动验证ID，避免出错/违规修改
- 支持对战的断线重连、比赛结果自动获取等，提供需要的接口 供 cube 调用。

### Cube

- 技术栈：采用 Next.js 前端，NestJS 后端，SQLite 数据库
- 所有状态在服务器上，任意用户可以断线重连
- 服务器保存有完整日志，游戏过程故障之后可以完整恢复状态，并且管理员可以回溯到历史状态
- 选牌期间，任意用户可以发起最多5分钟的暂停，由所有玩家投票决定，如果通过，则当前玩家选完牌后暂停。发起人或者管理员可以随时结束暂停。
- 对战期间，确定所有对局后自动连接 `srvpro` 建立游戏房间，并且轮询+更新状态
- 服务器不存储/传输卡图 pics，支持玩家browse指定本地 ygopro 路径自动读取卡图，否则 fallback 到空白卡图
- 比赛id + player id（玩家报名时输入）+ 报名时从服务器获取的token 构成玩家唯一鉴权方式，token自动进入cookie，但也支持手动输入。后端接受的所有输入都要包含这三个字段以定位+鉴权。
- 选牌/构筑过程的UI动画要求：
  - 顶部信息栏：player id, token (默认隐藏), 当前比赛基本信息（hover显示细节），当前牌堆、当前牌堆剩余牌数、剩余牌堆数目，正在选牌的player id，剩余时间 等信息；带卡牌搜索栏
  - 主要区域
    - 左侧是当前已选择卡牌，分为主卡组（main）、额外卡组（extra）、副卡组（side）三个区域，一律为每行10张卡牌，显示小卡图，scroll扩展，hover卡牌显示放大的卡图和具体的效果文本等信息。在YGO规则中，每张卡片进入主卡组还是额外卡组是确定的，副卡组既可以包含主卡组的卡片，也可以包含额外卡组的卡片。玩家可以随时通过拖动将已选择卡牌在主/副区域间交换或者区域内交换顺序。
    - 左侧各区域提示当前数目/上限数目
    - 右侧是待选卡牌，对于当前非自己选择的情况，只显示对应的数目（背面图案），对于当前轮到自己选择的情况，显示方式和左侧一致。每行5张卡牌。在该区域的背景动态显示选择剩余的秒数倒计时
    - 选择过程可以是点击或者拖动到左侧，点击时自动加入主卡组，如果拖动到main/extra和卡牌对应类型不正确则无效。拖动或点击后都弹出确认要求。
  - 选牌结束后，进入构筑阶段，此时右侧区域变为放弃区，仍显示构筑阶段倒计时，可继续通过拖动转移卡牌。随时可以点击按钮下载当前左侧选择区对应的ydk文件；确定好选择卡牌后可以锁定，服务器检验是否满足当前比赛数目要求，时限到达之前可以随时解锁。如果时间到达后不满足要求则发生随机填补/删除以满足限制。如果所有玩家提前完成锁定或者时间到，可以进入下一比赛阶段（排第一轮对战表并与srvpro建立房间，前端通知每个玩家服务器信息+房间密码）。
  - 注意合理的美术效果
