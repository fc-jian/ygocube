实际验收还修复了两个相关边界：浏览器拒绝 localStorage 时退出、字体设置和卡图回退仍可工作；大卡图包改为 64 MiB 分块续传，校验 206、强 ETag、范围和长度，6 次连续无进展才失败。curl 18/28 断流时只保留满足版本、范围和无内容编码变换条件的前缀；归档全量 CRC/路径/大小检查通过后才成为正式缓存。后者避免官方限速下反复丢弃下载进度。

旧版本已覆盖原始配置且没有可信快照或完整 config 事件时，回溯预览返回 HTTP 400 `REVERT_BASELINE_UNAVAILABLE`，不修改比赛或关闭房间。旧比赛从未保存的历史名称不能推断恢复。上述限制和会话规则已同步到 `07-protocol-api-design.md`。
